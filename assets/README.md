# assets

Déposer ici le logo définitif (`logo.svg` de préférence, sinon `logo.png` en 2x).

Ensuite, dans `index.html`, remplacer le bloc délimité par
`<!-- ▼▼ LOGO ... ▼▼ -->` / `<!-- ▲▲ fin du bloc logo ▲▲ -->` par :

```html
<img class="logo-img" src="assets/logo.svg" alt="Win Time">
```

La classe `.logo-img` est déjà stylée dans la feuille de styles.
