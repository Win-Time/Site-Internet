# assets

| Fichier | Usage |
|---|---|
| `win_time_80_logo.svg` | logo couleur d'origine (dégradé framboise → orange). Sert de favicon. |
| `win_time_80_logo_bw.svg` | déclinaison blanc et ink `#3D3D3C`, pour les fonds dégradés. Utilisée sur la page d'attente. |

La version blanc et noir reprend les mêmes tracés que l'originale :
le corps, la tête, l'anneau du cadran, les graduations et le point central
passent en blanc ; l'anneau extérieur, la couronne et le tiret passent en
ink `#3D3D3C`. Toute retouche du tracé doit être reportée dans les deux fichiers.
